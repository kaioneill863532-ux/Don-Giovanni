# Don Giovanni · The Final Defence

一款步行模拟器，底本是莫扎特的歌剧《唐璜》，以及 Derek Jarman 为它做的几何体舞台模型。

唐璜被拖进地狱的那一瞬间，在意识里分裂出一个没有记忆的自己（玩家），想让这个"没有偏见的人"原谅他。玩家戴上安娜、仆从和唐璜自己的面具，重新走过三段记忆，最后发现：没有人能替受害者原谅他。
